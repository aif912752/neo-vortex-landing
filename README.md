# NEO-VORTEX Hypercar Landing Page

A cinematic, Awwwards-style interactive landing page prototype for a next-generation electric hypercar. 

## 🌟 Features
- **Cinematic Hero**: Video background with seamless looping and custom typography.
- **Smooth Scrolling**: Powered by [Lenis](https://lenis.studiofreight.com/) for buttery smooth navigation.
- **Scroll Animations**: Advanced reveal and parallax effects using [GSAP & ScrollTrigger](https://greensock.com/).
- **Interactive 3D Elements**: Background particle matrix powered by [Three.js](https://threejs.org/).
- **Custom Cursor**: Cybernetic crosshair with lagging physics and hover states.
- **Interactive Configurator**: Real-time color selection with dynamic glow effects.
- **Editorial Layout**: Asymmetrical, luxury-focused UI built with [Tailwind CSS](https://tailwindcss.com/).

## 🚀 How to Run
This project is entirely self-contained in a single HTML file using CDN dependencies. 

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (Chrome, Safari, Firefox, Edge).
*Note: For the best experience and to avoid local CORS issues with video/canvas elements, it is recommended to run this via a local server (e.g., VS Code Live Server).*
